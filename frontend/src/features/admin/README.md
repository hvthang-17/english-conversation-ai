# admin

ADMIN-01: quản trị có phân quyền.

`AdminWorkspace` ghép tổng quan, tìm và khóa/mở tài khoản. `CatalogAdmin` quản lý chủ đề, tình huống và trình độ. Màn hình dùng lại API client Session/CSRF và thành phần phân trang của ứng dụng. Backend tiếp tục kiểm tra quyền cho mọi API quản trị. [Hợp đồng API](../../../../docs/api/admin.md)
